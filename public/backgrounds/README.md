# Stage background

Optional. Drop **one** file here and the stage uses it automatically:

```
stage.webp   (preferred)
stage.jpg
```

- **1080×1920** (vertical) or 2160×3840 for retina.
- No baked-in text, scores, or logos — the game draws those.
- Leave the middle relatively empty: that's where the sound title, waveform and
  score reveal sit.
- Keep the top ~15% and bottom ~10% calm; the header and footer live there.

The app puts a dark overlay on top, so don't worry if the art is bright.
If you want a separate lobby image later, tell me and I'll add `lobby.webp`.

Free, commercial-safe sources: unsplash.com (photos), freepik.com (attribution
required), svgrepo.com (vectors), kenney.nl (CC0 game art). Keep a CREDITS.md.
